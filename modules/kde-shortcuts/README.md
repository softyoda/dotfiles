# Raccourcis clavier KDE

| Raccourci | Action |
|---|---|
| `Meta+C` | basculer vers le cube (effet KWin) |
| `Meta+A` / `Meta+Maj+A` | activité suivante / précédente |
| `Ctrl+Alt+T` | désactivé (Konsole n'est plus lancé) |

Ne sont pas ici : F9 lecture/pause (`media-key-f9`), bouton power (`power-button`),
Alt+F9 HDMI (`hdmi-tv-recovery`), Ctrl+Maj+Échap (`mission-center-shortcut`).
